# JavaScript Coursework Repository

This repository holds all of my JavaScript coursework for the next few weeks. It starts with the basics—simple HTML pages, console output, and small scripts—and gradually builds into more complex assignments as the course progresses. Everything here is organized by week so I can track my progress and keep things clean.

## What’s Included
- HTML files for each assignment  
- JavaScript examples and exercises  
- Console output demonstrations  
- Hosted versions of each project (FTP uploads)  
- Any supporting files used throughout the course  

## Purpose
The goal of this repo is to keep all my JavaScript work in one place while I move through the class. It covers:
- Basic DOM manipulation  
- Working with HTML attributes  
- Changing CSS styles through JavaScript  
- Event handling and user interaction  
- General practice writing and testing JavaScript code  

## Notes
This repo will grow over time as each week introduces new concepts. I’ll update folders, add new examples, and keep everything versioned so it’s easy to follow the progression from simple scripts to more advanced JavaScript work.
